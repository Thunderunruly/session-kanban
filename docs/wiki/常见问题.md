# 常见问题

[English](FAQ) | **简体中文**

## 安装后侧栏没有「会话看板」图标

- 确认已重载 DSH 窗口（不是只切换面板）；
- 确认插件已加入当前 profile 的依赖：`dsh plugin --profile web add dsh-session-kanban`；
- 检查插件是否加载成功（插件管理器里应有 `dsh-session-kanban` 记录）。

## 归档后跳回了「新对话」首页

1.1.3 起已修复：如果归档的是主视图当前持有的会话，看板会在宿主清空主视图后自动重新打开。
仍出现时请确认版本 ≥ 1.1.3，并完整重载窗口。

## 「进行中 / 有待办 / 已完成」里的会话比「全部」少

- 这是过滤语义：三个内容 tab 各管一类，不是分页截断；
- 详情尚未加载的会话会先归入「已完成」，加载后自动移动到正确分类；
- 如果叠加了团队范围 / 工作区过滤，tab 结果也会随之收窄。

## 子代理会话显示「父会话不可见」

说明父会话已归档或不在当前可见数据里。此时父标题不可点击，避免打开失败。

## 子代理会话无法重命名

这是宿主限制：子代理路由持有的会话标题由路由管理，重命名会被宿主拒绝。插件把该操作禁用，
悬停会显示原因。

## 工作区过滤时看不到某些子会话

1.1.4 起子会话会沿父会话链继承工作区；若仍缺失，请确认父会话本身属于该工作区，或该会话是被
宿主直接登记到了别的工作区。仍异常请附上环境信息反馈。

## 热力图工作日标注不准

- 在 **设置 → 通用设置** 里确认国家/地区选择正确；
- 点击热力图侧栏的刷新图标立即重新拉取；
- 联邦制国家只支持国家级假日（见 [工作日数据源](数据源) 的已知限制）；
- 某些国家在 Nager.Date 没有数据，暂时只有周末规则。

## 下拉框弹出方向或高度不合适

下拉会按触发器上下剩余空间自动选择方向与最大高度，长列表在卡片内部滚动。如果仍被遮挡，请
反馈具体位置与窗口大小。

## 升级后界面没变化

- 完整重载窗口；
- 确认 profile 中安装的是新版本（`dsh plugin --profile web add dsh-session-kanban@latest`）；
- 客户端 bundle 由宿主缓存，必要时重启 DSH。

## 数据会发到哪里？

插件只由浏览器请求公开的节假日接口，并在本地 `localStorage` 缓存；不发送凭据、会话内容或
个人信息，也没有遥测。详见 [工作日数据源](数据源)。

## 如何反馈问题

在 [GitHub Issues](https://github.com/Thunderunruly/session-kanban/issues) 提交，附上：

- DSH 版本、插件版本；
- 复现步骤与截图；
- 控制台报错（如有）。
