# 工作日数据源

热力图的工作日 / 非工作日标注来自浏览器直接拉取的公开节假日数据。数据**按国家缓存**在
`localStorage`，按设置中的自动更新间隔重新获取；热力图侧栏的刷新图标可随时手动更新。

## 来源

| 国家/地区 | 数据源 | 说明 |
| --- | --- | --- |
| 中国 | [holiday-cn](https://github.com/NateScarlet/holiday-cn) 镜像（jsDelivr，其次 raw.githubusercontent.com） | 法定节假日、调休补班与调整后的周末 |
| 日本 | [holiday-jp](https://github.com/holiday-jp/holiday_jp) | 内阁府节假日，含振替休日与国民休日 |
| 韩国 | [holidays-kr](https://github.com/hyunbinseo/holidays-kr) | 含替代休日 |
| 俄罗斯 | [isdayoff.ru](https://isdayoff.ru) | 生产日历，含调休工作日 |
| 其他国家 | [date.nager.at](https://date.nager.at) | 公共假日 + 当地周末规则 |

## 回退与缓存

- 专用源不可达时，**按年份**回退到 Nager.Date；界面显示的来源名称跟随实际使用的数据；
- 缓存按国家保存 `{ years, fetchedAt, source }`；旧版本缓存缺少 `source` 时会自动刷新一次；
- 内置 2023–2026 中国数据快照，离线时看板仍可用。

## 状态行解读

热力图侧栏底部一行：

```
↻ 中国 · 2026/10/26 · Holiday CN
```

依次是：刷新图标（可点击立即更新）· 国家 · 最近刷新日期（YYYY/MM/DD）· 数据来源。悬停可查看
完整状态与标注规则（例如「节假日来源 + 周末规则」）。

## 已知限制

- 数据为**国家级**。德国、加拿大、澳大利亚、西班牙、瑞士等国的州/省节假日不一致，需要二级
  行政区选择器，暂未实现，这些国家只显示国家级公共假日。
- Nager.Date 目前没有阿联酋、沙特、以色列、泰国、马来西亚、印度的数据集，这些国家暂时只按
  周末规则标注，等待后续接入专门数据源。
- 部分国家（如美国、英国）的「州/省假日」不会出现在国家级列表里。

## 隐私

- 仅由浏览器向上述公开、CORS 接口直接请求；
- 结果只缓存在本地 `localStorage`；
- 不发送任何凭据、会话内容或个人信息，插件不含遥测。
