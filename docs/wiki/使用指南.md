# 使用指南

[English](Usage) | **简体中文**

## 打开看板

点击左侧栏的「会话看板」面板图标，主区域打开看板。首屏是**概览页**，用 Tab 可以切到「全部」
卡片列表。

## 概览页

- **统计卡片**：会话总数、运行中、今日活跃、待办完成（仅统计已加载详情的会话）。
- **活跃分布**：GitHub 风格热力图，可切换 **年 / 月 / 周 / 日**；按当前选择的国家高亮工作日
  （绿）与非工作日（黄/橙），并给出「活跃度 / 工作日 / 非工作日」三组图例。
- **年份 / 月份 / 周 / 日**：随热力图刻度切换；高亮开关可单独关闭工作日或非工作日标注。
- **日历状态行**：热力图侧栏底部一行紧凑状态——刷新图标 · 国家 · 最近刷新日期
  `YYYY/MM/DD` · 数据来源，例如 `↻ 中国 · 2026/10/26 · Holiday CN`。悬停可查看完整状态与
  标注规则，点击刷新图标立即更新。

## Tab 语义

| Tab | 内容 |
| --- | --- |
| 概览 | 统计与热力图，聚合结果跟随搜索/范围过滤 |
| 全部 | 所有可见会话的瀑布流卡片 |
| 进行中 | 运行中的会话 |
| 有待办 | 有未完成待办的会话（含运行中的会话） |
| 已完成 | 没有未完成待办的会话：全部完成、没有待办清单或详情尚未加载 |

「进行中 / 有待办 / 已完成」合起来覆盖「全部」中的每一条会话，不会出现只存在于「全部」里的
会话。

## 搜索

搜索框同时过滤卡片列表与概览统计，匹配标题、当前工作、最近结果、任务文本与目录路径。清空搜索
即恢复。

## 范围过滤

- **团队范围**（范围）：存在 Agent Team 时，可按团队收窄到 Lead 与其成员会话。
- **工作区**：按工作区收窄（默认「全部工作区」；只有一个工作区时隐藏该下拉；选择会记住）。
  子代理 / 团队成员 / 分叉子会话由宿主直接记入工作区时按直接归属，否则沿父会话链继承所属
  工作区，因此不会在选中父会话所在工作区时被漏掉。
- 团队范围、工作区过滤、Tab 与搜索**可以叠加**。

## 卡片信息

- 状态圆点（运行中 / 空闲）与相对更新时间；
- 标题：会话标题（行内重命名见下）；
- 会话关系：**子代理 / 团队成员**子会话显示 `↳ 关系 · 父会话标题`，父会话显示 `↳ N 个子会话`；
  同一家族左侧色边与圆点同色，父标题可点击打开父会话；**分叉会话是独立顶层会话**（fork 来源只作溯源），
  不显示父关系、也不计入子会话；父会话已归档时仍显示标题并标注「已归档」；
- 当前工作（运行中）或最近进展（空闲），以及最近任务；
- 待办进度条与待办列表（最多显示 4 项，其余折叠提示）；
- 工作目录（`basename`）与悬停操作按钮。

## 卡片操作

悬停卡片底部出现操作：

| 操作 | 说明 |
| --- | --- |
| 置顶 / 取消置顶 | 置顶会话排在最前 |
| 重命名 | 行内编辑；子代理路由持有的会话不可重命名，按钮禁用，悬停会说明原因 |
| 分叉 | 从最近完成回合创建新的分叉会话 |
| 复制 Session ID | 复制完整会话 ID |
| 归档 | 需二次确认；若归档的是主视图当前持有的会话，归档后会自动重新打开看板 |
| 刷新 / 新建会话 | 位于页面右上角 |

键盘：卡片可聚焦，Enter / 空格打开会话；重命名输入框 Enter 提交、Esc 取消。

## 卡片点击与误触

- 只有点击卡片本体才会打开会话；底部工具栏区域不触发跳转；
- 按下后拖动超过阈值或存在文本选择时视为拖拽/选择，不会误打开会话；
- 父会话链接、操作按钮、归档确认按钮都各自阻止冒泡。
